Quick help

  

    
Say something
start
print "Hello!"
# a comment
end
A program begins with start and finishes with end. Words in quotes are text. A line that begins with # is a note for people; the computer skips it.

    
Keep a value
define score = 0
set score = score + 1
print score
define makes a new name. set gives it a new value.

    
Make a choice
if score > 10
  print "You made it."
else
  print "Keep going."
Lines pushed in by two spaces belong to the line above them.

    
Choose on one line
define age = 16
if age = under 18 = print "Teenager"
if age = over 18 = print "Adult"
under 18 means less than 18. over 18 means 18 or more.

    
Do it again
define n = 0
repeat 3
  print "Again!"

until n = 3
  set n = n + 1
repeat 3 does it 3 times. until keeps going until the thing is true.

    
Ask a question
define ask{1} = ("Your name?")
define ask{2} = ("Your age?")
ask{1}
ask{2}
print ("Hi ") answer{1} ("Age:") answer{2}
define ask{1} writes the question. ask{1} asks it. answer{1} is what the person typed.

    
Your own command
define greet(name)
  return "Hello " + name

print greet("Ada")
A function is a few lines with a name. return gives back the result.

    
A list
define pets = ["cat", "dog"]
print pets[1]
append(pets, "owl")
print length(pets)
The first item is number 1. append adds one at the end. length counts.

    
Luck
random 67
  print "This one."
random 33
  print "Or this one."
Only one of the blocks runs. The numbers are the chances and add up to 100.
