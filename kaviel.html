THE ESSENTIALS
A language that reads like you think.

  

    
Say something
start
print "Hello!"
# a comment
end
Wrap your program in start and end. Use # for comments.

    
Keep a value
define score = 0
set score = score + 1
print score
define creates a name. set changes its value.

    
Make a choice
if score > 10
  print "You made it."
else
  print "Keep going."
Indent the lines inside a block. Two spaces keep things readable.

    
One line, one decision
define age = 16
if age = under 18 = print "Teenager"
if age = over 18 = print "Adult"
under 18 means below 18. over 18 means 18 or older.

    
Do it again
define n = 0
repeat 3
  print "Again!"

until n = 3
  set n = n + 1
repeat counts. until checks before each turn.

    
Ask, then answer
define ask{1} = ("Your name?")
define ask{2} = ("Your age?")
ask{1}
ask{2}
print ("Hi ") answer{1} ("Age:") answer{2}
define ask{n} prepares a question. ask{n} asks it. answer{n} holds its latest response as text.

    
Your own commands
define greet(name)
  return "Hello " + name

print greet("Ada")
A function keeps a few lines under one name. return sends a value back.

    
A list of things
define pets = ["cat", "dog"]
print pets[1]
append(pets, "owl")
print length(pets)
Positions start at 1. append adds at the end, length counts.

    
Leave room for chance
random 67
  print "This one."
random 33
  print "Or this one."
Consecutive random blocks form one draw. The weights add up to 100.
